One-time setup:

  1. Create a free ThingSpeak channel with field1 = latitude and field2 = longitude.
  2. In the code below, replace YOUR_CHANNEL_ID and YOUR_READ_API_KEY with your channel details. Leave the read key empty if the channel is public.
  3. Configure your Arduino to send fresh GPS coordinates to ThingSpeak through SIM800L GPRS.
  4. Upload this index.html file to a GitHub repository and enable GitHub Pages.

Privacy: anyone who can access a public channel may be able to view its location data. Use a private channel and keep credentials out of public code where appropriate.

The page checks for new data every 20 seconds. The real update rate depends on GPS signal, cellular coverage, battery power, and the ThingSpeak service.
